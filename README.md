# Butterfly

**Shipping now: [Cocoon](packages/cocoon)**, a typed, disk-backed,
Firestore-style local database for Dart and Flutter, built on SQLite
(`dart pub add cocoon`). Benchmarked against drift, Isar, ObjectBox, Hive CE
and sembast up to 1,000,000 records: see
[Performance](https://docs.page/redfieldchristabel/butterfly/libraries/cocoon/performance).

**Coming soon:** the rest of Butterfly (`butterfly_cli`, `core_management*`,
`auth_management*`). They are documented on the
[docs site](https://docs.page/redfieldchristabel/butterfly) and can be tried
from git today, but are not on pub.dev yet.
