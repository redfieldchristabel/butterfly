---
title: Screen layout
description: Read MediaQuery size, a shortest-side breakpoint, and the current theme from BuildContext.
---

## Use the extension

```dart
import 'package:core_management/extensions/screen_layout.dart';
import 'package:flutter/material.dart';

class LayoutSummary extends StatelessWidget {
  const LayoutSummary({super.key});

  @override
  Widget build(BuildContext context) {
    final size = context.screenSize;
    return Padding(
      padding: EdgeInsets.all(context.mobileLayout ? 8 : 16),
      child: Text(
        '${size.width} x ${size.height}; shortest: ${context.shortestSide}',
        style: context.themeData.textTheme.bodyMedium,
      ),
    );
  }
}
```

Place the widget under the appropriate `MediaQuery` and theme, normally supplied by `MaterialApp`.

## Available getters

| Getter | Exact source |
| --- | --- |
| `screenSize` | `MediaQuery.of(context).size` |
| `shortestSide` | `MediaQuery.of(context).size.shortestSide` |
| `mobileLayout` | `shortestSide < 600` |
| `themeData` | `Theme.of(context)` |

The breakpoint uses logical pixels and the shortest side, not available layout width or the operating system. Exactly 600 returns `false`. A wide window with a short height can still return `true`.

There are no separate tablet/desktop getters, orientation API, or responsive widget builder in this extension. Use `LayoutBuilder` for parent constraints or Flutter's `MediaQuery` APIs when you need more than these four shortcuts.

Implementation: `packages/core_management/lib/extensions/screen_layout.dart`.
