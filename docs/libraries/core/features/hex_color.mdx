title: Hex colors
description: Parse RGB or ARGB strings and format Flutter colors with alpha first.
---

## Convert colors

Import the extension directly; it is not exported by the core barrel.

```dart
import 'package:core_management/extensions/hex_color.dart';

void main() {
  final color = HexColor.fromHex('#42A5F5');
  assert(color.toHex() == '#ff42a5f5');
  assert(color.toHex(leadingHashSign: false) == 'ff42a5f5');
  assert(color.toHex(withOpacityFormat: false) == '#42a5f5');

  final translucent = HexColor.fromHex('8042A5F5');
  assert(translucent.toHex() == '#8042a5f5');
}
```

## API

| API | Behavior |
| --- | --- |
| `HexColor.fromHex(String hexString)` | Parses hexadecimal into a `Color` |
| `color.toHex()` | Lowercase `#aarrggbb` by default |
| `leadingHashSign: false` | Omits `#` |
| `withOpacityFormat: false` | Omits the alpha byte |

Use six-digit `RRGGBB` or eight-digit `AARRGGBB`, optionally prefixed with `#`. Six-digit input gets opaque alpha `ff`. Eight-digit input has **alpha first**, not CSS-style `RRGGBBAA`.

## Input limitations

The implementation detects six-digit input by total string length (6 or 7), removes the first `#`, and delegates to `int.parse(..., radix: 16)`. It does not trim, expand shorthand such as `#fff`, or strictly validate the documented lengths. Invalid hexadecimal can throw `FormatException`; do not assume every unsupported length is rejected. Validate user-entered color strings before conversion.

Implementation: `packages/core_management/lib/extensions/hex_color.dart`.
