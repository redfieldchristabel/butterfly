title: Hex Colors
description: Parse 6-digit RGB or 8-digit ARGB hex strings and format Flutter Color instances.
---

The `HexColor` extension on `Color` converts between hexadecimal color strings and Flutter's `Color` class, using **alpha-first (`#aarrggbb`)** ordering for 8-digit values.

## Quickstart & runnable test

Import `package:core_management/extensions/hex_color.dart` directly:

```dart title="test/hex_color_test.dart (suggested)"
import 'package:core_management/extensions/hex_color.dart';
import 'package:flutter_test/flutter_test.dart';

void main() {
  test('converts between hex strings and colors', () {
    final color = HexColor.fromHex('#42A5F5');
    expect(color.toHex(), '#ff42a5f5');
    expect(color.toHex(leadingHashSign: false), 'ff42a5f5');
    expect(color.toHex(withOpacityFormat: false), '#42a5f5');

    final translucent = HexColor.fromHex('8042A5F5');
    expect(translucent.toHex(), '#8042a5f5');
  });
}
```

---

## API reference

<Property name="HexColor.fromHex(String hexString)" type="Color" required>
  Parses a 6-digit (`RRGGBB` / `#RRGGBB`) or 8-digit (`AARRGGBB` / `#AARRGGBB`) hexadecimal string into a `Color`.
  - **6-digit input** (total string length `6` or `7`): Automatically prepends opaque alpha `ff`.
  - **8-digit input:** Interprets the first two hex digits as the alpha channel (`AARRGGBB`), **not** CSS-style `RRGGBBAA`.
</Property>

---

<Property name="color.toHex({bool leadingHashSign = true, bool withOpacityFormat = true})" type="String">
  Formats a `Color` as a lowercase hexadecimal string:
  - `toHex()` → `'#ff42a5f5'` (default: `#` prefix + 2-digit alpha + 6-digit RGB)
  - `toHex(leadingHashSign: false)` → `'ff42a5f5'`
  - `toHex(withOpacityFormat: false)` → `'#42a5f5'` (strips the alpha byte)
</Property>

---

## Input validation & caveats

<Warning>
  **Validate user input before calling `fromHex`:** The implementation checks `hexString.length == 6 || hexString.length == 7` to decide whether to prepend `'ff'`, strips the first `'#'`, and passes the result to `int.parse(..., radix: 16)`. It does **not** expand 3-digit CSS shorthand (`#fff`), trim whitespace, or reject arbitrary string lengths that happen to parse as base-16 integers. Invalid characters throw a `FormatException`.
</Warning>
