title: Typography theme
description: Wrap ThemeData with overridable instance getters for current Material text styles.
---

## Create a typography instance

`CoreTypographyTheme` takes a `ThemeData` instance. Its getters are not static, and it does not provide legacy `bodyText1`, `headline2`, or `caption` names.

```dart title="lib/widgets/welcome_text.dart (suggested)"
import 'package:core_management/core_typography_theme.dart';
import 'package:flutter/material.dart';

class WelcomeText extends StatelessWidget {
  const WelcomeText({super.key});

  @override
  Widget build(BuildContext context) {
    final typography = CoreTypographyTheme(Theme.of(context));
    return Text('Welcome', style: typography.headlineMedium);
  }
}
```

This example creates the wrapper from the current theme in `build`, so it follows inherited theme changes. An instance retained elsewhere continues to reference the `ThemeData` supplied when it was constructed.

## Available styles

The instance exposes `displayLarge/Medium/Small`, `headlineLarge/Medium/Small`, `titleLarge/Medium/Small`, `bodyLarge/Medium/Small`, and `labelLarge/Medium/Small`.

Each has a corresponding primary getter, such as `primaryHeadlineMedium` or `primaryBodyLarge`, backed by `ThemeData.primaryTextTheme`. `textTheme` and `primaryTextTheme` rebuild their respective text themes using these getters; `textSelectionTheme` forwards the supplied theme's value.

## Customize by subclassing

Getters have no setters. Override them in a subclass rather than assigning to a static property.

```dart title="lib/services/typography.dart (suggested)"
import 'package:core_management/core_typography_theme.dart';
import 'package:flutter/material.dart';

class AppTypography extends CoreTypographyTheme {
  AppTypography(super.themeData);

  @override
  TextStyle get bodyLarge => super.bodyLarge.copyWith(fontWeight: FontWeight.w500);
}
```

To integrate with `BaseThemeService`, override its `coreTypographyTheme` getter to return your subclass using initialized `iTheme`. Call `theme(context)` before reading theme-dependent getters.

## Limitations

Individual style getters use null assertions on the supplied text themes. Supply fully populated Material text themes; missing styles can throw. The wrapper does not register a global theme, listen for theme changes, or provide runtime theme-mode switching.

Implementation: `packages/core_management/lib/core_typography_theme.dart` and `lib/services/base_theme.dart`.
