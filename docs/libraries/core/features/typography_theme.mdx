---
title: Typography Theme
description: Wrap ThemeData with overridable Material 3 text style getters and integrate custom typography with BaseThemeService.
---

`CoreTypographyTheme` (`package:core_management/core_typography_theme.dart`) wraps a Flutter `ThemeData` instance and exposes overridable getters for every Material 3 text role—both standard (`textTheme`) and primary (`primaryTextTheme`).

## Usage & customization

<Tabs>
  <TabItem label="Read styles in a widget" value="read-typography">
    Construct `CoreTypographyTheme(Theme.of(context))` inside `build()` so your widget automatically reacts to inherited theme changes:

    ```dart title="lib/widgets/welcome_text.dart (suggested)"
    import 'package:core_management/core_typography_theme.dart';
    import 'package:flutter/material.dart';

    class WelcomeText extends StatelessWidget {
      const WelcomeText({super.key});

      @override
      Widget build(BuildContext context) {
        final typography = CoreTypographyTheme(Theme.of(context));
        return Text('Welcome', style: typography.headlineMedium);
      }
    }
    ```
  </TabItem>
  <TabItem label="Subclass & wire into BaseThemeService" value="subclass-typography">
    Style properties on `CoreTypographyTheme` are getters (not mutable fields). To customize typography across your app, subclass `CoreTypographyTheme`, override the getters you want to tweak, and return your subclass from `BaseThemeService.coreTypographyTheme`:

    ```dart title="lib/services/typography.dart (suggested)"
    import 'package:core_management/core_typography_theme.dart';
    import 'package:flutter/material.dart';

    class AppTypography extends CoreTypographyTheme {
      AppTypography(super.themeData);

      @override
      TextStyle get bodyLarge => super.bodyLarge.copyWith(fontWeight: FontWeight.w500);
    }
    ```

    When overriding `coreTypographyTheme` inside your `ThemeService`, pass `iTheme` (`AppTypography(iTheme)`) and ensure `theme(context)` has been called first.
  </TabItem>
</Tabs>

## Available style getters

Every role below is an **instance getter** on `CoreTypographyTheme` (there are no static getters and no legacy Material 2 names like `bodyText1`, `headline2`, or `caption`):

| Scale Family | Standard (`ThemeData.textTheme`) | Primary (`ThemeData.primaryTextTheme`) |
| --- | --- | --- |
| **Display** | `displayLarge`, `displayMedium`, `displaySmall` | `primaryDisplayLarge`, `primaryDisplayMedium`, `primaryDisplaySmall` |
| **Headline** | `headlineLarge`, `headlineMedium`, `headlineSmall` | `primaryHeadlineLarge`, `primaryHeadlineMedium`, `primaryHeadlineSmall` |
| **Title** | `titleLarge`, `titleMedium`, `titleSmall` | `primaryTitleLarge`, `primaryTitleMedium`, `primaryTitleSmall` |
| **Body** | `bodyLarge`, `bodyMedium`, `bodySmall` | `primaryBodyLarge`, `primaryBodyMedium`, `primaryBodySmall` |
| **Label** | `labelLarge`, `labelMedium`, `labelSmall` | `primaryLabelLarge`, `primaryLabelMedium`, `primaryLabelSmall` |

### Composite theme getters

<Property name="textTheme / primaryTextTheme" type="TextTheme">
  Rebuilds a complete `TextTheme` from all 15 standard or primary getters above, so any getter you override in a subclass automatically flows into the resulting `TextTheme`.
</Property>

---

<Property name="textSelectionTheme" type="TextSelectionThemeData">
  Forwards `themeData.textSelectionTheme` directly.
</Property>

<Warning>
  Each individual style getter uses a non-null assertion (`!`) on the underlying `ThemeData.textTheme` / `primaryTextTheme` field (for example, `_themeData.textTheme.bodyLarge!`). Always pass a Material `ThemeData` whose text themes are populated.
</Warning>
